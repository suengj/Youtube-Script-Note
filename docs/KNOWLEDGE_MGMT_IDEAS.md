# 지식 관리 시스템 - 메모 및 글쓰기 기능 아이디어

## 1. 메모 관련

### 1.1 메모 마크다운 렌더링
- **현재**: 메모 tree에 80자 미리보기만 표시
- **개선**: 메모 항목 클릭 시 전체 내용을 마크다운으로 렌더링하여 패널 내 또는 모달로 표시
- **구현**: `loadMemos`에서 메모 클릭 시 `marked.parse(content)` 적용, `.memo-item` 확장 뷰 또는 슬라이드 패널

### 1.2 메모 수정
- **현재**: 메모는 생성·삭제만 가능
- **개선**: 메모 항목 클릭 후 "수정" 버튼 → textarea에 로드 → 저장 시 GitHub API `PUT` (sha 필요)
- **구현**: `memo.js`에 `editMemo(noteId, fileName, sha)` 추가

### 1.3 메모 정렬/필터
- **아이디어**: 생성일 기준 정렬 (최신순/오래된순), 메모 내 검색
- **구현**: `loadMemos`에서 정렬 옵션, 검색어로 `content` 필터

### 1.4 메모 내 링크
- **아이디어**: 메모 본문에 `[[노트명]]` 작성 시 클릭 가능 링크로 렌더링
- **구현**: 메모 렌더링 시 `sanitizeWikiLinks` + `findNoteByWikiRef` 재사용

---

## 2. 노트(원본 MD) 태그 관리

### 2.1 태그 추가/수정 UI
- **현재**: 태그는 MD frontmatter에서만 추출. 뷰어에서 태그 추가 기능 없음
- **개선**: 노트 헤더에 "태그 편집" 버튼 → 모달에서 태그 추가/삭제 → GitHub API로 해당 MD 파일 frontmatter 수정
- **구현**: `GET` 원본 → frontmatter 파싱 → `tags` 배열 수정 → `PUT` (base64 content, sha)
- **주의**: MD 본문과 frontmatter를 정확히 유지해야 함

### 2.2 태그 자동 제안
- **아이디어**: 기존 태그 목록에서 자동완성, 또는 파일명/내용 기반 추천
- **구현**: `getAllTags()` 결과를 드롭다운에 표시, 입력 시 필터

---

## 3. 글쓰기 및 노트 관리

### 3.1 인라인 노트 편집
- **아이디어**: 뷰어에서 노트 본문을 직접 편집 후 저장
- **구현**: "편집" 모드 토글 → `contentEditable` 또는 textarea → `PUT` GitHub API
- **난이도**: 중 (충돌 처리, 저장 실패 시 롤백)

### 3.2 노트 생성
- **아이디어**: 날짜 폴더 선택 후 "새 노트" 버튼 → 제목 입력 → 빈 MD 생성
- **구현**: `PUT /api/github/.../contents/notes/{date}/{fileName}.md` (빈 content 또는 템플릿)

### 3.3 노트 복제/템플릿
- **아이디어**: 현재 노트를 복사하여 새 노트로 저장, 또는 템플릿에서 생성
- **구현**: `GET` 원본 → `PUT` 새 경로

---

## 4. 지식 그래프/연결

### 4.1 백링크
- **아이디어**: "이 노트를 참조하는 노트" 목록 표시
- **구현**: `content-index` 또는 별도 `backlinks-index.json`에서 `[[현재노트]]` 포함 노트 검색

### 4.2 관련 노트 추천
- **아이디어**: 현재 노트와 태그/내용이 유사한 노트 추천
- **구현**: 태그 겹침 수, 또는 본문 키워드 유사도 (단순화: 같은 태그 보유 노트)

---

## 5. 우선순위 제안

| 순위 | 기능 | 난이도 | 설명 |
|------|------|--------|------|
| 1 | 메모 마크다운 렌더링 | 낮음 | 메모 클릭 시 전체 내용 마크다운 표시 |
| 2 | 메모 수정 | 낮음 | 기존 메모 내용 수정 후 저장 |
| 3 | 태그 추가 UI | 중 | 노트에 태그 추가/삭제 (frontmatter 수정) |
| 4 | 메모 내 [[링크]] | 낮음 | 메모에서 노트 링크 클릭 가능 |
| 5 | 노트 생성 | 중 | 새 MD 파일 생성 |
| 6 | 백링크 | 중 | 이 노트를 참조하는 노트 목록 |
